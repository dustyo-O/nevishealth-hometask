# Tasks — 003 Clients Trend Chart

Spec: `functional-spec.md` (FR1–FR9, 45 acceptance criteria) · How: `technical-considerations.md` (§1–§4) · Reviews: `reviews/TRIAGE.md` (spec review F1–F5, tech review F1–F3) · The consult that measured it all: `consults/react-frontend-chart-sections-20260922-234604.md`.

Everything lives in `apps/web`, so the slices are sequential and each is one lane. Slice 1 makes the chart appear; slice 2 carries the riskiest unknown — the accessibility structure, which is the reason we are not using the charting library's own keyboard layer at all.

## Standing rules

- Read `CLAUDE.md`, then `functional-spec.md`, then `technical-considerations.md`, then the consult. The tech doc is the contract, and its numbers were **measured in a real browser against a Recharts 3.10.1 prototype** — not guessed. Do not "improve" a value without re-measuring and saying so in your ledger note.
- `type` aliases over `interface`, everywhere. CSS Modules with tokens — no Tailwind, no inline style objects for static styles. FSD import direction downward only; every slice exposes `index.ts`.
- **`recharts` is imported in exactly one file, `ui/bar-plot.tsx`.** If another file seems to need it, the code is in the wrong place — report it rather than spreading the dependency.
- **`accessibilityLayer={false}`.** The library's keyboard layer fails six of this spec's criteria and has no reset API (consult Q2). Everything a screen reader or a keyboard user touches is ours.
- Tests are written with the change and proven RED first (temporarily revert, watch it fail, restore). Never delete or skip a test to make a gate green. A completion claim cites fresh output from this run.
- Pure functions are tested without Recharts and without a DOM. `yScale`, `toMonthlySeries`, `sparseMonthIndices`, `describeMonth` and the reader reducer all carry their own tests.
- **jsdom has no `ResizeObserver`**, so `ResponsiveContainer` renders no SVG there and a component test would silently assert against an empty `div` (consult Q4). Settle this in slice 1 — `initialDimension` through a prop, or a stub in the Vitest setup — and say which you chose.
- Gate before you finish: `pnpm check:web`. Not green → `PARTIAL`, with the failure quoted. The e2e server is on **5273** (`reuseExistingServer: false`); if you start a dev server for your own exploration, use another port or the gate will test the wrong tree.
- Every finished sub-task ends with `_(Done <date>: what actually happened, incl. surprises)_`.
