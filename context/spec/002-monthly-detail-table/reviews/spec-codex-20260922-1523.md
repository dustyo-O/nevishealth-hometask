### F1: Left-arrow requirements contradict each other
- severity: major
- where: functional-spec.md:FR3
- problem: Left on a row name is specified both to collapse or move to its parent and to leave focus unchanged.
- evidence: “Left on an open row closes it” conflicts with “Left on the row's name … leave[s] the outline where it is.”
- fix: Limit the no-op case to Left on the closed Company row.

### F2: Scroll strategy does not guarantee the required vertical position
- severity: major
- where: technical-considerations.md:D-7 and §3 R2
- problem: `scrollIntoView({ block: 'nearest' })` can scroll the page vertically when the target row is outside the viewport. A horizontal walk on an already visible row does not justify closing this risk.
- evidence: FR3 requires no vertical page movement when revealing a month; D-7 only reports a twelve-step horizontal walk at one page position.
- fix: Adjust only the table container's horizontal scroll position, and test entering a month on a partially offscreen row.

### F3: Departing rows remain exposed to assistive technology
- severity: major
- where: technical-considerations.md:§3 “leaving rows linger”
- problem: Collapsed descendants remain in the accessibility tree during the exit animation. Disabling pointer events and setting `tabindex="-1"` does not hide them from screen-reader navigation.
- evidence: The plan explicitly retains rows for approximately 250 ms with stale hierarchy attributes and calls this “harmless.”
- fix: After recovering focus, immediately mark departing rows `aria-hidden="true"` and inert; keep them only for visual animation.

### F4: Verbatim-value test cannot distinguish recalculated totals
- severity: minor
- where: technical-considerations.md:§4 clients-table.test.tsx
- problem: Testing Company values of 250 and 350 against the shipped fixture cannot prove the table uses stored values rather than summing children.
- evidence: The product definition states that every parent's values now equal the sum of its children.
- fix: Add a component fixture whose stored parent value differs from its children’s sum, and assert that the stored value renders.

## Verdict
SHIP WITH FIXES

Resolve the conflicting keyboard rule, scrolling guarantee, accessibility exposure during collapse, and ineffective stored-value test before implementation acceptance.
