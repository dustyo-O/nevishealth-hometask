### F1: Mouse focus and keyboard cursor can diverge
- severity: major
- where: apps/web/src/shared/ui/tree-grid/model/use-tree-grid.ts:handleKeyDown
- problem: Clicking a figure can focus its `tabIndex="-1"` cell without updating the cursor. Subsequent keys operate on the previous cursor, potentially toggling Company when Enter is pressed on a figure.
- evidence: `TreeGridCell` permits native focus, but no focus handler synchronizes it; `handleKeyDown` always uses `current.cursor`. The mouse test checks HTML equality, which cannot detect changed focus.
- fix: Prevent pointer clicks on figures from moving focus, as FR2 requires, and add a click-then-keyboard regression test.

- severity: major
- where: apps/web/src/widgets/clients-table/ui/clients-table.module.css:reveal overlay
