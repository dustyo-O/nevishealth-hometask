### F1: Keyboard users cannot reach a leaf row’s figures
- severity: major
- where: functional-spec.md:FR3
- problem: Right enters monthly figures only on an already-open row. Leaves cannot open, so their figures have no defined keyboard entry.
- evidence: “Right on a closed row opens it; Right on a row that is already open moves into that row's first monthly figure.”
- fix: Specify that Right on a leaf’s name moves to its first monthly figure.

### F2: Collapsing an ancestor can discard keyboard focus
- severity: major
- where: functional-spec.md:FR2; Assumptions to challenge
- problem: A user can focus a descendant’s figure and then click an ancestor to collapse it. The spec removes the focused row but requires the user to stay where they were, leaving focus recovery undefined.
- evidence: Closing a branch hides all descendants; the assumption says “the user stays where they were.”
- fix: When collapse hides the focused element, move focus and the table’s sole tab stop to the collapsing ancestor.

### F3: Figure navigation leaves several keys ambiguous
- severity: minor
- where: functional-spec.md:FR3
- problem: Home, End, Enter and Space have no explicit behavior when a figure is focused. Implementers could apply row commands or cell navigation, producing different test outcomes.
- evidence: The figure-specific paragraph defines only Left, Right, Up and Down; earlier commands refer to the “current row.”
- fix: Define those four keys in figure mode and specify whether navigation stops at the first/last row and month.

### F4: Truncated names are unavailable to sighted keyboard and touch users
- severity: minor
- where: functional-spec.md:FR5
- problem: The full visual name is available only through hover. Keyboard users without a screen reader and phone users have no specified way to reveal it.
- evidence: “The full name is still available by hovering over it and is what a screen reader reads.”
- fix: Reveal the full name on keyboard focus and provide a touch-accessible disclosure that does not interfere with expansion.

## Verdict
SHIP WITH FIXES

Resolve the keyboard entry, focus recovery and name disclosure gaps, and make figure-mode key behavior explicit before implementation.
